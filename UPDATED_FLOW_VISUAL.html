📊 Updated Data Flow

Step 1: User Input

User fills out the form with:

  • Theme (e.g., "Smart Cities")
  • Constraints (optional)
  • Team size (default: 4)
  • Duration (default: 48 hours)
↓

Step 2: Generate Initial Ideas

POST /api/generate

Request: { "theme": "Smart Cities", "constraints": ["IoT", "Low-cost"] } Response: { "problems": ["Traffic congestion", "Energy waste"], "existing_solutions": ["Smart traffic lights", "Solar panels"], "idea_concepts": [ { "name": "CityPulse", "description": "Real-time city monitoring platform", "target_audience": "City planners" }, { "name": "GreenRoute", "description": "AI-powered eco-friendly navigation", "target_audience": "Daily commuters" } ] }
↓

Step 3: Display Ideas

Frontend shows beautiful cards with:

  • Name - Clear project title
  • Description - What the idea does
  • Target Audience - Who will use it
  • Button - "Get Detailed Plan"
↓ (User clicks button)

Step 4: Request Detailed Plan

POST /api/plan/detailed

Request: { "idea_concept": { "name": "CityPulse", "description": "Real-time city monitoring...", "target_audience": "City planners" }, "team_members": 4, "duration_hours": 48 } Response: { "idea_name": "CityPulse", "work_process": "Use Agile with daily standups...", "timeline_summary": "48h: Planning (6h), Dev (30h)...", "suggested_tech_stack": [ "React", "Node.js", "MongoDB", "IoT Sensors" ], "plan_steps": [ { "phase": "Planning & Setup", "tasks": ["Define requirements", "Setup env"] } ] }
↓

Step 5: Display Detailed Plan

Frontend shows comprehensive plan with:

  • ⚙️ Work process methodology
  • ⏱️ Timeline breakdown
  • 💻 Tech stack badges
  • 📋 Phase-by-phase tasks
