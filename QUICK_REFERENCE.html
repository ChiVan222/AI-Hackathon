🚀 AI Hackathon Idea Generator

Quick Reference Guide - FastAPI + Next.js + Gemini AI

📋 Prerequisites Checklist

Python 3.8+ installed
Node.js and npm installed (Download here)
Backend dependencies installed: pip install -r requirements.txt
Frontend dependencies installed: cd frontend && npm install

🏃 Quick Start (3 Steps)

Step 1: Start Backend
cd e:\Projects\AI-Hackathon
.\run.bat
✅ Backend running at: http://localhost:8000
Step 2: Start Frontend
cd e:\Projects\AI-Hackathon\frontend
npm run dev
✅ Frontend running at: http://localhost:3000
Step 3: Open Application
🎉 Visit: http://localhost:3000
⚡ Even Faster: Run .\start-all.bat from the root directory to start both servers automatically!

🌐 URLs Reference

Service URL Description
Frontend http://localhost:3000 Main application UI
Backend http://localhost:8000 API root (health check)
